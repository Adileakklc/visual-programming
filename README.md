## Nasıl Çalıştırırım?

### Seçenek A — Visual Studio (Önerilen)
1. Repoyu indir/clone et
2. **Visual Studio**’da ilgili klasörü aç:
   - Eğer klasörün içinde `.sln` dosyası varsa onu açıp **Run**’a bas
   - `.sln` yoksa: yeni bir C# proje açıp ilgili `.cs` dosyasını projeye ekleyebilirsin
3. `Ctrl + F5` (Debug’sız çalıştır) ya da `F5` (Debug ile)

### Seçenek B — Visual Studio Code
- C# eklentisi ile klasörü açıp çalıştırabilirsin (projeye göre ayar gerekebilir).

> Eğer istersen, bana hangi klasörde hangi dosyanın ana giriş noktası olduğunu söylersen README’ye “tek tıkla çalıştırma” için net adım da eklerim.
